# Авторизация и управление доступом

## Модель для tenant-деплоя (сервер вуза)

Каждый вуз поднимает **свой** инстанс со **своей** БД. Данные (расписание, карты, участники) управляются через админку на этом сервере.

### 1. Root при деплое (env)

При развёртывании кластера вуз задаёт в `.env`:

```env
DEPLOYMENT_MODE=tenant
TENANT_SLUG=sstu
ROOT_ADMIN_EMAIL=dekan@yandex.ru
YANDEX_CLIENT_ID=...
YANDEX_CLIENT_SECRET=...
```

**Root** — не отдельный пароль, а **почта Яндекс ID**, указанная в `ROOT_ADMIN_EMAIL`.  
При первом входе через Яндекс с этой почтой человек автоматически получает роль **ADMIN** в своём вузе.

Root нельзя понизить или удалить через админку.

### 2. Регистрация пользователей

Все входят через **Яндекс ID** — отдельной регистрации с паролем нет.

Первый вход создаёт запись пользователя в БД (email, yandexId, имя, аватар).

### 3. Добавление в вуз (админка)

`/o/{slug}/admin/members`:

1. Пользователь **хотя бы раз** вошёл через Яндекс ID на этом сервере.
2. Root или назначенный им **администратор** добавляет его по почте: роль (студент / преподаватель / сотрудник), группа.
3. Пользователь получает доступ к порталу вуза.

**Назначать других администраторов** может только **root** (кнопка «Сделать админом»).

Обычные админы могут добавлять студентов и преподавателей, но не могут назначать ADMIN.

### 4. Опционально: резерв по почте

В том же разделе (свёрнутый блок) — можно заранее добавить почту до первого входа. Когда человек войдёт через Яндекс, доступ откроется автоматически.

## Яндекс OAuth

1. [oauth.yandex.ru](https://oauth.yandex.ru/) → приложение.
2. Redirect URI: `https://ваш-домен.ru/api/auth/callback/yandex`
3. Права: `login:email`, `login:info`, `login:avatar`

```env
AUTH_SECRET=...   # openssl rand -base64 32
AUTH_URL=https://ваш-домен.ru
```

---

## Локальная разработка

Без `ROOT_ADMIN_EMAIL` + `TENANT_SLUG` seed создаёт демо-аккаунты:

- `admin@sstu.local` / `password123`

С `ALLOW_DEV_LOGIN=true` или `NODE_ENV=development` доступен вход email/пароль.

---

## Нет доступа к вузу

Пользователь вошёл через Яндекс, но админ ещё не добавил его → `/access-pending?org=sstu`.

---

## Hub (межвузовские чаты)

Tenant: `HUB_BASE_URL=...` — общий слой на отдельном сервере. Один Яндекс ID на всех инстансах.
